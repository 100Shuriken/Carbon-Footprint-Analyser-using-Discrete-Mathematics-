Functions · partitions

What one year emits

Each activity a has an emission factor f(a) in kg CO₂e per unit. A person's profile is a function q(a) giving how much of each activity they do in a year. The footprint is the sum of the two multiplied together.

F(q) = Σa ∈ A f(a) · q(a)

The five categories partition the activity set: every activity belongs to exactly one, so the category totals add up to the whole.

Propositional logic

Advice from rules

The profile sets the truth value of each atomic proposition, such as drives_a_lot. Each piece of advice is a rule P → advice. When P is true, the advice applies (modus ponens).

Click a rule to see its truth table. The highlighted row matches the person you picked.

Combinatorics · power sets

The best reduction plan

A plan is any subset of the candidate actions, so n actions give 2n plans. The search checks every subset, skips the ones that break a conflict (you can't go vegetarian and vegan at once) or go over the effort budget, and keeps the plan that saves the most.

Move the budget to see how the best plan changes.

Recurrence relations

Year by year

If a fraction r of emissions is cut every year and a constant b is added back, the footprint follows a first-order linear recurrence. Its closed form comes from the characteristic-root method.

Eₙ = (1 − r)·Eₙ₋₁ + b
Eₙ = aⁿE₀ + b(1 − aⁿ)/(1 − a), a = 1 − r

When 0 < r < 2 the sequence converges to the fixed point E* = b / r.

Sets · partial orders

Who is greener?

Say P ≼ Q when P emits no more than Q in every category. This relation is reflexive, antisymmetric and transitive, so it is a partial order. It is not a total order, because some pairs can't be compared.

The Hasse diagram keeps only the covering edges, with the greenest people at the bottom.

Graph theory

The lowest-carbon way to travel

Cities are vertices and each transport link is an edge, with one edge per mode. An edge's weight is its distance times the mode's emission factor. Dijkstra finds the lowest-carbon route, Dijkstra on distance finds the shortest one, and BFS finds the one with the fewest legs.

Equivalence relations

Emission bands

Two activities are related when their emission factors fall in the same band. The relation is reflexive, symmetric and transitive, so it is an equivalence relation. Its equivalence classes split the activities into four disjoint groups.

The Python package carbon_analyser computed every figure on this page, using the same tested code as the command line (python -m carbon_analyser web). The page itself only re-evaluates the recurrence's closed form when you move its sliders.

Emission factors are rounded public figures (UK DESNZ/DEFRA, India CEA grid baseline, Our World in Data). The five people are invented examples, and distances between cities are approximate.
